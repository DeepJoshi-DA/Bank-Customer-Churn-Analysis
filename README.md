# Bank Customer Churn Analysis

## Project Overview
A complete Data Analytics project analyzing 
bank customer churn patterns using 10,000 
customer records.

## Tools Used
- Microsoft Excel — Data Cleaning
- SQL Server — Data Analysis (10 Queries)
- Power BI — Interactive Dashboard
- DAX — Custom Measures

## Key Findings
- Overall Churn Rate — 20.37%
- Germany & France contribute 80% of churn
- Age group 40-50 churns the most
- High balance customers churning = revenue risk
- Inactive members 2x more likely to churn

## Dataset
- Records: 10,000 rows
- Columns: 13
- Source: Kaggle — Churn Modelling Dataset
